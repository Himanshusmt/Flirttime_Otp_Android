The root is a thin Gradle orchestrator: `settings.gradle.kts` registers Google/MavenCentral repositories, enables `RepositoriesMode.FAIL_ON_PROJECT_REPOS` so child modules cannot declare their own repos, applies the foojay toolchain resolver, and includes only `:app`. `build.gradle.kts` at the root only declares the Android application/library plugins with `apply false`, deferring actual configuration to the app module. Shared version and plugin aliases live in `gradle/libs.versions.toml` (referenced by both root and children), while `gradle.properties` sets JVM args, enables the Gradle configuration cache, and pins Kotlin code style. The root thus enforces repository isolation and a single source of truth for versions across the multi-module build.
