The module follows a layered split: `data/` and `domain/repository/` define a Retrofit-backed `UserRepository` contract (username availability, profile updates, photo upload) consumed uniformly by every presentation subpackage. Presentation is divided into four independent flows — onboarding (`intro/`), dialog pickers (`dialog/`), photo preview (`preview/`), and verification (`verification/`, `gesture/`) — each owning its own Activity + ViewModel pair and reaching the shared repository without depending on one another; cross-flow state is passed via callbacks from the dialog layer back to the onboarding activity.
