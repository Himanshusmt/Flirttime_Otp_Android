Flat presentation layer under `com.flirttime.feature.onboarding.presentation` containing four `AppCompatActivity` subclasses: three sequential intro screens (`Intro1Activity`, `Intro2Activity`, `Intro3Activity`) and one permission-gating screen (`PermissionActivity`). Each Activity owns a ViewBinding instance, applies edge-to-edge insets via `EdgeToEdgeHelper.setupEdgeToEdge`, and delegates navigation exclusively through `AppNavigator.navigateTo(...)` with typed `Destination` values (e.g. `Destination.Intro2`, `Destination.Webview`, `Destination.Login`). State persistence is delegated to `SessionManager` injected via Koin (`by inject()`). There is no ViewModel or use-case layer inside this module — it is purely UI glue between XML layouts and the shared core navigation/session primitives.
