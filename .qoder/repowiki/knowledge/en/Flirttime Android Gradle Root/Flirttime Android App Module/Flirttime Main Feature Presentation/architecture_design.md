The package is a flat collection of sibling feature sub-packages under `presentation/`, each owning its own Fragment, adapters, models, and `Mock*Provider` classes — there is no shared orchestrator or navigation layer inside this scope. Cross-child wiring happens outside this module: child Fragments are registered with the app's bottom-navigation/tab host from elsewhere in the codebase. Each screen is self-contained, using local data classes and mock providers rather than cross-feature dependencies, so the parent role is purely organizational.
