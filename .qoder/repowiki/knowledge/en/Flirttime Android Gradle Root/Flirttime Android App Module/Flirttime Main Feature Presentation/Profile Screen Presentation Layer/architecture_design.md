Single-fragment UI module under `com.flirttime.feature.main.presentation.profile`. `ProfileFragment.kt` is the sole entry point: it inflates `FragmentProfileBinding`, wires click listeners (edit cover, settings, add moment, voice record/player, premium upgrade), toggles between empty-record and active-player states in the 'My Voice' section, and navigates to `Destination.AddMoment` via `AppNavigator`. Two custom `View`s live in the `widget/` sub-package — `AudioWaveformView` draws rounded amplitude bars on a Canvas, and `ProfileProgressRingView` renders a circular progress arc driven by a `progress` property. The fragment handles window insets (`WindowInsetsCompat`) to position top actions below the status bar and display cutout. There is no ViewModel or repository here; data is currently passed as literal parameters into `setupUserProfileHeader`.
