Single-screen presentation module under the main feature's `presentation` layer. `ChatFragment` is the entry point: it owns two `RecyclerView`s (pinned + regular) backed by two instances of `ChatsAdapter`, binds a search `EditText` via `TextWatcher` to filter `ChatItem` lists case-insensitively on name/lastMessage, and delegates data loading to `MockChatProvider.getChats()`. `ChatItem` is a plain data class carrying all row state (avatar URL/resource, pin/story/verified flags, last message, timestamp, unread count, delivery/read flags). The adapter renders each row using ViewBinding (`ItemChatRowBinding`) and delegates avatar loading to `ShimmerHelper.loadWithShimmer` from `core.common`. There is no dependency on a domain or data layer — this screen is fully self-contained for UI-only work.
